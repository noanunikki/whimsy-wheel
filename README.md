# Whimsy Wheel

A tiny decision toolbox that runs in the browser: a spinning **decision wheel**, a 3D **coin flip** and a **dice roller** (d4–d20).
No dependencies, no build step, no tracking. Everything is stored locally in your browser.

**Live:** https://noanunikki.github.io/whimsy-wheel/

## Features
- Wheel with editable options, presets, shuffle and a "remove winner after spin" mode
- 3D coin with heads/tails statistics
- Dice with real pips on d6, 1–4 dice at a time
- History of results, sound effects (Web Audio), confetti, light and dark theme
- Installable as an app (PWA) and works offline

## Run locally
```bash
python3 -m http.server 8080
```
Then open http://localhost:8080.
